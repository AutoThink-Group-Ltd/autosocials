# Brand Voice — AutoSocials

Provisional. Update as the brand voice evolves; do not duplicate these rules in code.

- Confident, direct, friendly. Founder-led tone, not corporate.
- Short sentences. Active voice. No filler.
- Plain English over jargon. Explain a metric in one line if it appears.
- Use **creators**, not "leads".
- Use **scanning** / **live search**, not "scraping".
- Always reference the year as **2026** in marketing/UX copy.
- No emojis in product UI unless the user uses them first.
- When uncertain, say so and ask one focused question.
