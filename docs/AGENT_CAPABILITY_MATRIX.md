# Agent capability coverage matrix

Branch inventory, 22 November 2026. This is a source map, not a statement of deployed availability, authenticated client compatibility or successful end-to-end operation. The user-facing app, Sam's internal registry and the separate public MCP catalogue are different execution surfaces. Registration in `tools/registry.ts` is a frontend descriptor; its handler explicitly reports server-only and does not itself make a tool available through MCP. Consult `src/lib/agent-access-contract.ts` and `/mcp-tools.json` for the current branch MCP contract, actual scopes and runtime gates. OAuth and workspace authorisation apply; a tool being listed is not an external action authorisation.

## Acceptance and next steps

For each adapter, record the exact catalogue name, method, scope, feature gate, source data, side effects, user/owner authorisation, provider or credit implications, current implementation status and a successful isolated test. Confirm denied cross-workspace and missing-scope requests as well as allowed reads; exercise write confirmations and hold states only in an approved test environment. Maintain a clear unknown where evidence is missing. No production release or live customer mutation was performed for this inventory.
