# Contributing to AutoSocials

Use GitHub issues for reproducible bugs and feature proposals. Submit focused pull requests with a short description of the change and the checks you ran. For larger changes, open an issue first to discuss the intended behaviour.

Contribute only code or assets you have the right to share under this repository's AGPL-3.0-only licence. Include any required attribution. Use synthetic test data and keep credentials, real account identifiers and production exports out of commits. For vulnerabilities, use the private route in [SECURITY.md](SECURITY.md).
