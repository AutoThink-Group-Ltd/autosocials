# Security

Use [GitHub private vulnerability reporting](https://github.com/AutoThink-Group-Ltd/autosocials-community/security/advisories/new) to contact the maintainers about a security issue. Include the affected revision, impact and a minimal demonstration using synthetic data. Keep credentials and personal data out of reports.

The current public default branch is the supported source for security fixes. Monitor the private report for maintainer questions and status updates.
